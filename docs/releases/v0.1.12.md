This preview revises the limiter for smoother peak control on a mix bus.

- A finite gain ramp uses the full 3 ms lookahead before a peak reaches the output.
- **Auto release** adapts recovery to sustained limiting. Turn it off for fixed recovery with W1's published release-time convention.
- Existing limiter presets and sessions load with Auto release enabled. Their limiter sound changes in this version.

The algorithm uses published design principles with original Short Bus tuning. Direct listening comparisons against W1 remain pending. [Limiter details](https://github.com/AlphaFatti/short_bus/blob/v0.1.12/docs/limiter.md)

### Install

| Platform | ZIP | Place `Short Bus.vst3` in |
| --- | --- | --- |
| Apple Silicon Mac | `Short-Bus-v0.1.12-macOS-arm64.zip` | `~/Library/Audio/Plug-Ins/VST3/` |
| Windows x64 | `Short-Bus-v0.1.12-Windows-x64.zip` | `C:\Program Files\Common Files\VST3\` |

Extract the ZIP and copy the entire bundle into the folder. Rescan in REAPER or your VST3 host. In OBS on Windows, load it through atkAudio PluginHost or PluginHost2. The Mac build is ad hoc signed and unnotarized.

For feedback, include the OS, host, release setting, Drive, approximate gain reduction, and whether Auto release was enabled. [Report feedback](https://github.com/AlphaFatti/short_bus/issues/new)
